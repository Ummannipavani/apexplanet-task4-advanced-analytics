# 📊 Task 4 - Advanced Analytics & Statistical Modeling

## 📌 Overview

This project was completed as part of the **Data Analytics Internship** at **ApexPlanet Software Pvt. Ltd.** The objective of this task is to perform advanced analytics on the SuperMarket Sales dataset using statistical techniques, time series analysis, customer segmentation, and predictive modeling.

---

## 🎯 Objectives

- Perform descriptive statistical analysis
- Analyze data distribution using visualization
- Conduct hypothesis testing
- Perform time series analysis and sales forecasting
- Segment customers using K-Means Clustering
- Build predictive models for sales prediction
- Evaluate machine learning model performance

## 📈 Analysis Performed

### 1. Statistical Analysis
- Mean
- Median
- Standard Deviation
- Skewness
- Kurtosis
- Correlation Analysis
- Hypothesis Testing (Independent t-test)

### 2. Time Series Analysis
- Daily Sales Trend
- Monthly Sales Trend
- Sales Forecasting using ARIMA

### 3. Customer Segmentation
- Feature Scaling
- Elbow Method
- K-Means Clustering
- PCA Visualization
- Silhouette Score

### 4. Predictive Modeling
- Linear Regression
- Decision Tree Regression
- Model Evaluation using:
  - MAE
  - RMSE
  - R² Score

---

## 📊 Key Insights

- Statistical analysis summarized the distribution and characteristics of sales.
- Correlation analysis identified relationships among numerical features.
- Time series analysis highlighted sales trends over time.
- K-Means clustering grouped customers with similar purchasing behavior.
- Predictive models successfully estimated sales using product-related features.
